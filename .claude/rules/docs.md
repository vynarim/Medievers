# Règles — documentation

- `docs/GDD.md`, `TECH_SPEC.md`, `ASSETS.md` et `BACKLOG.md` sont les sources de vérité. Interviens par modifications localisées, jamais par réécriture globale sans demande.
- Une règle de jeu modifiée dans le code est modifiée dans le GDD dans le même commit.
- Les décisions techniques sont des ADR : `docs/adr/NNNN-titre.md`, avec contexte, options, décision et conséquences.
- Les rapports des skills vont dans `docs/reports/<type>/` et les playtests dans `docs/playtests/`.
- Les docs sont en français, les identifiants et le code cités restent en anglais.
